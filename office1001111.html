Addition Custom Task with Generative AI


It was found that LLM AI such as ChatGPT can add user custom task very quickly (In my test single prompt was enough). Here is the procedure that I tested:


LLM model used in this test: ChatGPT5.5

1. Drag and drop the Operant House software file (OperantHouse*.py) into ChatGPT.

2. Enter a prompt like this:
       “This Python code is the software for the Operant House. Please add a [name of task] task to it.”

3. Put the code generated by ChatGPT into the Operant House folder and run it.


In my test it worked perfectly and the whole process took only a few minutes...
